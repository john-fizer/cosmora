# Cosmora — Brand Brief

## What It Is
Cosmora is a personal cosmic intelligence system — a professional-grade astrology OS that calculates, interprets, and narrates the timing of a person's life using ancient Hellenistic techniques, modern psychological astrology, and AI reasoning. It is not an astrology website. It is an instrument.

## The Big Idea
**"The cosmos has always held the map. Cosmora reads it for you."**

Most astrology apps feel like a horoscope column got a UI. Cosmora feels like you've been given access to a machine that was built in 2070, found in a vault, and contains everything the ancients knew — displayed with the precision of a scientific instrument.

## Positioning
- **Category**: Cosmic intelligence tool (new category — not astrology app, not AI chat)
- **Audience**: Intellectually curious, design-literate adults who take self-knowledge seriously but want depth over novelty
- **Tone**: Precise. Oracular. Never mystical for mystical's sake — always grounded in real technique
- **Price Signal**: Premium. This is not free-tier energy.

## Personality
| Trait | Expression |
|-------|-----------|
| Precise | Uses correct technical terms (Hellenistic, sect, dignity, profection). Numbers are exact, not rounded. |
| Oracular | Speaks with conviction — the Oracle does not hedge. |
| Restrained | Doesn't scream for attention. The design is confident, not desperate. |
| Cosmic | The vocabulary is celestial: void, orbit, transit, eclipse. |
| Intelligent | Explains the *why* behind the *what*. Not just "Mercury Rx" but what that means for *your* chart. |

## Visual Language

### Typography
- **Display**: Cormorant Garamond — editorial serif, carries cosmic gravitas, feels ancient-intelligent
- **Body**: Outfit — clean geometric grotesque, readable, modern-professional
- **Data/Mono**: Fragment Mono — for degrees, coordinates, house numbers, astrological data

### Color System
- **Void** `#08080F` — Primary background. Almost black, a hint of deep space blue.
- **Surface** `#0E0E1A` — Card/panel backgrounds
- **Elevated** `#14142A` — Hover states, active surfaces
- **Border** `rgba(255,255,255,0.07)` — Hairline. Barely visible. Precision over decoration.
- **Solar** `#C8A55B` — Gold accent. Sun placements, premium states, CTAs. Warm, not neon.
- **Oracle** `#7B6FD4` — Violet. Oracle, AI, mystical states. Subdued, not electric.
- **Data** `#4ECDC4` — Teal. Data, coordinates, technical readouts. Cool, precise.
- **Text Primary** `#EAE6F4` — Light lavender-white. Not harsh white.
- **Text Secondary** `#7A7690` — Muted mid-tone. Labels, secondary information.
- **Text Subtle** `#3A3650` — Very dark. Disabled states, decorative text.

### Motion Language
Cosmora moves like celestial objects — with gravity, intention, and predictable orbital logic.

- **Page reveals**: Staggered fade-up from slight vertical offset (12–16px). Feels like matter crystallizing.
- **Scroll reveals**: Elements enter as the viewport crosses them — not dramatic, precise.
- **Hover states**: Subtle lightening of the surface, hairline border brightens. No scaling on cards.
- **Orb/planetary elements**: Slow rotation, subtle pulse. Not frantic.
- **Data updates**: Smooth number transitions. Values don't just snap.
- **Transitions**: Short (200ms) for interactive, medium (400ms) for reveals, long (600–800ms) for page entrances.

### Spatial Rhythm
- 8px base grid
- Generous outer margins (24–48px depending on viewport)
- Cards have significant internal padding (20–28px)
- Section dividers are hairlines, not heavy borders
- Whitespace is a design element, not an accident

## Voice & Copy
- Headings: Short, declarative, cosmic. "The Oracle Speaks." "Transit Radar." "Your Natal Configuration."
- Body: Technical but accessible. Uses correct terminology, explains in context.
- System states: Poetic precision. Not "Loading..." — "Reading the cosmos..."
- Errors: Honest, calm. "Signal lost." "No chart data." Never apologetic.
- CTAs: Direct. "Begin." "Ask the Oracle." "Generate Report."

## Anti-Patterns (what Cosmora is NOT)
- Not purple-gradient-on-white "AI vibes"
- Not neon glow on every element — glow is reserved for states that matter
- Not emoji-heavy copy
- Not generic astrology symbols used decoratively without meaning
- Not a dashboard full of widgets — an instrument full of insights
- Not another "Space Grotesk + violet" generic dark app

## The One-Sentence Test
**"Does this feel like a cosmic machine that reveals hidden structure, or does it feel like a dark-mode website with stars?"**

If it's the latter — redesign it.
