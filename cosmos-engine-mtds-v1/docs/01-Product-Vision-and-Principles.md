# 01 — Product Vision and Principles

## Core vision

Cosmos Engine gives users a way to walk inside their own life. The app is spatial, symbolic, cinematic, and adaptive. It does not merely answer questions; it discovers structure.

## Primary rooms

### Observatory

The user's life as a 4D sky. Natal placements are origin anchors. Transits animate through time. Events appear as stars. Derived points and patterns form constellations.

### Library

The textual and media archive. Every journal entry, note, voice memo, photo, document, dream, and goal is stored as an object connected to graph nodes.

### Cinema Room

The narrative renderer. It turns life chapters, symbolic patterns, and future scenarios into scripts, trailers, storyboards, voiceovers, and generated scenes.

### Mirror Room

The reflective room. It hosts Future Self, Past Self, Shadow, Inner Child, and Mentor agents. It is for guided reflection, not prediction.

### Council Chamber

The multi-agent research chamber. Hellenistic, Vedic, modern psychological, Uranian, Jungian, numerology, statistical, and narrative agents independently analyze the same evidence and publish findings.

### Director Simulator

The counterfactual room. It lets the user ask “What if I move?”, “What if I stay?”, “What if I build this company?”, and “What if I change nothing?” The output is scenario comparison, not fate.

## Product principles

### 1. The graph is the product

Every screen is a view into the same universe. No duplicated state. No isolated notebooks. No disconnected chat history.

### 2. Determinism before interpretation

Astrological calculations, event timestamps, house systems, and derived points must be deterministic, testable, and reproducible before any agent interprets them.

### 3. Meaning is layered

Meaning is not one label. A memory can carry emotional meaning, planetary meaning, narrative meaning, psychological meaning, relational meaning, and statistical meaning.

### 4. Forecasts are probability fields

The system does not predict fixed events. It estimates likely themes, windows, tensions, and opportunities based on personal history, transits, graph similarity, and model confidence.

### 5. Discovery beats generic interpretation

The strongest output is not “Saturn means discipline.” The strongest output is “Across your last four Saturn activations, the recurring life pattern was career pressure followed by identity restructuring.”

### 6. The user remains sovereign

The user can correct events, reject interpretations, hide memories, delete data, disable agents, and request why an output was generated.

## Anti-patterns

Do not build a horoscope feed. Do not build a generic AI therapist. Do not create deterministic fear language. Do not hide uncertainty. Do not let a video generator produce scenes without provenance. Do not let agents write over canonical truth.
