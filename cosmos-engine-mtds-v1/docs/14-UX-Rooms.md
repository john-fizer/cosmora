# 14 — UX Rooms

## Purpose

Define the major product rooms and how they access the same underlying Cosmos graph.

## Navigation model

The application is a spatial command center. Rooms are not separate apps; each room is a lens on the same universe.

## Observatory

Primary use cases:

- View natal chart as origin constellation.
- Overlay transits.
- Scrub through time.
- Explore life events.
- Reveal mirror and midpoint geometry.
- Discover constellations.

Primary components:

- 4D canvas.
- Time scrubber.
- Layer toggles.
- Node inspector.
- Transit timeline.
- Pattern drawer.

## Library

Primary use cases:

- Search memories.
- Read journals.
- View media.
- Edit events.
- Approve extracted memories.

Primary components:

- Object search.
- Event editor.
- Media grid.
- Memory cards.
- Provenance panel.

## Cinema Room

Primary use cases:

- Generate life trailers.
- Generate yearly highlight reels.
- Generate possible future scenes.
- Review scripts and storyboards.

Primary components:

- Script panel.
- Storyboard timeline.
- Voiceover selector.
- Visual style selector.
- Render queue.

## Mirror Room

Primary use cases:

- Talk with Future Self.
- Reflect with Past Self.
- Explore Shadow patterns.
- Ask what a chapter is teaching.

Primary components:

- Agent conversation.
- Evidence drawer.
- Reflection prompts.
- Journal save button.

## Council Chamber

Primary use cases:

- Ask for expert interpretation.
- Compare astrology systems.
- See consensus and disagreement.
- View skeptical review.

Primary components:

- Council table.
- Finding cards.
- Agent votes.
- Evidence graph.
- Confidence meter.

## Director Simulator

Primary use cases:

- Ask “what if?”
- Compare life branches.
- Explore tradeoffs.
- Generate scenario scripts.

Primary components:

- Scenario builder.
- Branch comparison.
- Assumption editor.
- Probability delta chart.
- Action map.

## Onboarding flow

1. Birth profile.
2. Life chapter survey.
3. Top turning points.
4. Relationship and career timeline.
5. Initial natal observatory.
6. First discovered pattern.
7. Consent settings.

## Acceptance criteria

- Every room can explain which graph objects it is using.
- Users can edit canonical facts from any room.
- Forecasts remain visually distinct from memories.
- AI outputs have evidence drawers.
- Rooms work progressively; user does not need all data connected.
