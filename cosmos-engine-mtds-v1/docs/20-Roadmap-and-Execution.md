# 20 — Roadmap and Execution

## Purpose

Define build phases, team structure, and implementation order.

## Phase 0 — Canon and architecture

Duration: 2–4 weeks.

Deliverables:

- MTDS v1 accepted.
- Ontology frozen for MVP.
- Database schemas drafted.
- API contracts drafted.
- Design language drafted.
- Build backlog created.

## Phase 1 — Deterministic core

Duration: 6–8 weeks.

Deliverables:

- Auth.
- Birth profile.
- Event Service.
- Astrology Engine.
- Natal chart calculation.
- Transit calculation.
- Derived points.
- Golden chart tests.

## Phase 2 — Living graph

Duration: 6–8 weeks.

Deliverables:

- Graph Projection Service.
- Neo4j schema.
- Event-star graph.
- Symbolic activation edges.
- Vector memory service.
- Basic graph queries.

## Phase 3 — Observatory alpha

Duration: 8–10 weeks.

Deliverables:

- 4D renderer MVP.
- Natal anchors.
- Transit overlay.
- Event stars.
- Time scrubber.
- Layer toggles.
- Node inspector.

## Phase 4 — Agent council alpha

Duration: 8–10 weeks.

Deliverables:

- Reality Engine.
- Symbolic Interpreter.
- Skeptic Agent.
- Moderator Agent.
- Finding objects.
- Evidence drawer.

## Phase 5 — Probability engine alpha

Duration: 8–12 weeks.

Deliverables:

- Motif retrieval.
- Personal recurrence scoring.
- Forecast object schema.
- Scenario-safe language.
- Feedback loop.
- Probability cloud visualization.

## Phase 6 — Cinema alpha

Duration: 10–14 weeks.

Deliverables:

- Script generation.
- Storyboard generation.
- Voiceover draft.
- Video prompt pack.
- Render queue.
- User approval flow.

## Team roles

- Chief Architect.
- Product Designer.
- Frontend / 3D Engineer.
- Backend Engineer.
- Data / Graph Engineer.
- Astrology Systems Engineer.
- ML Engineer.
- AI Orchestration Engineer.
- DevOps / Security Engineer.
- QA / Evaluation Engineer.

## MVP scope

The first real MVP should include:

- Birth profile.
- Manual event timeline.
- Natal chart.
- Transit overlay.
- Antiscia and midpoint toggles.
- Event stars.
- Basic pattern explanation.
- Text-only life chapter summary.

Do not build video generation first. The universe and graph must exist first.
